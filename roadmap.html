Roadmap

What's next.

Priorities, not promises. These can change as we learn.

  • Now
    Fix the autonomy tiers

    manual and smart currently behave the same, and yolo doesn't unlock anything new. The intended safe, medium, and dangerous split isn't wired up.

  • Now
    Better default model

    deepseek-r1:1.5b fumbles tool calls. We're looking at a default that can use the five tools reliably.

  • Next
    Session browsing

    Sessions are saved as JSON, but there's no way to list or resume them from the CLI. That's a gap.

  • Next
    Guardrail tests

    The shell guardrails are regex-based. We want a test suite that covers the patterns they claim to catch.

  • Next
    Documentation pass

    The README covers setup and tools. It could do a better job of explaining the goal loop and the critic call.

Disagree with a priority?

Open an issue and make the case. We read all of them.
