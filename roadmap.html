Roadmap

What's next.

Priorities, not promises. These can change as we learn.

  1. Done
    October 15, 2026 Improved error handling

    Clearer messages and graceful recovery when a tool call fails. No more silent drops.

  2. Done
    October 15, 2026 Faster startup time

    Cold start is now under 400 ms. We trimmed the initialization path and deferred optional checks.

  3. Done
    October 16, 2026 Fix the autonomy tiers

    manual, smart, and yolo now map to three distinct permission levels. The safe, medium, and dangerous split is fully wired up — no more identical behavior.

  4. Done
    October 16, 2026 Better default model

    The default model now calls all five tools reliably. We swapped out deepseek-r1:1.5b for something that holds up under real workloads.

  5. Now
    October 18, 2026 Session browsing

    Sessions are persisted as JSON, but there's still no way to list or resume them from the CLI. We're closing that gap with agent0 sessions.

  6. Now
    October 18, 2026 Guardrail tests

    The shell guardrails are regex-based, and we want proof they work. A new test suite will cover every pattern they claim to catch.

  7. Now
    October 18, 2026 CLI output theming

    Respecting NO_COLOR and adding a --theme flag so the agent looks good in any terminal.

  8. Next
    Within 3 days Documentation pass

    The README covers setup and tools, but the goal loop and the critic call deserve a proper walkthrough. That rewrite lands within the next three days.

  9. Next
    Within 3 days Plugin system for tools

    A lightweight way to register custom tools without modifying the core. We're sketching the interface now.

  10. Planned
    Agent-1

    The successor to Agent-0. Still on the drawing board — expect deeper autonomy, better long-horizon planning, and a real memory layer.

  11. Planned
    Agent-1:mini

    A faster, version of Agent-1 and designed to-do AI R&D for speedup
