Help

Setup and common questions.

Install steps, backend choices, and what the agent will do on its own.

How do I install Agent-0?

Clone the repository and run app.sh. You'll need Python 3.10 or later.

The script refuses to run if stdin isn't a TTY, because half the interaction is input() prompts.

On first launch, defaults are written into db/local/. Ollama is the default backend and deepseek-r1:1.5b is the default model.

Which model should I use?

The default model, deepseek-r1:1.5b, is tiny and will fumble tool calls. Swap it as soon as you can.

Use /model in the REPL, or edit the config directly. If ollama list shows a model, /model will take it.

How does the Groq backend work?

From the REPL, run /api gsk_... with your key. That saves the key with mode 600 and switches you to Groq in one step.

You can also set AGENT0_GROQ_API_KEY in your environment. That wins over the stored key.

What tools does Agent-0 have?

Five: shell, web_search, fetch_url, memory_append, and memory_write.

The list isn't extensible at runtime and isn't meant to be. There's no dedicated file-reading tool. If you want the agent to look at a file, it uses shell with cat, head, or grep.

Will it run shell commands on its own?

No. Shell always requires [Y]es/[N]o. No autonomy level changes that.

There are guardrails for rm -rf /, fork bombs, dd of=/dev/..., mkfs, force-pushing to main, and curl | bash. They're regexes, so they'll miss things.

What are the autonomy levels?

Four: manual, smart, auto, and yolo.

In practice, manual and smart behave identically, and yolo doesn't unlock anything auto doesn't already have. The intended tiers were safe, medium, and dangerous, but _autonomy_ok only checks the medium flag. That's a known gap.

Where do notes and sessions go?

Notes live in memory.md. Sessions are saved as JSON.

The agent can also chew on a goal in the background with /goal. Separate budgets apply for steps, tool calls, and wall time.

Where can I report a bug?

Open an issue on the Agent-0 repository.

Still stuck?

Open an issue and describe what you tried. Include your OS and Python version.
