About OpenBrain-LLC.

We build Agent-0. The name and premise come from the Agent-0 in AI-2027. This is the version you can install.

What Agent-0 is

A CLI agent that runs on your machine. You type at it, it thinks, it calls tools. It keeps notes in a markdown file, saves the session as JSON, and can work on a goal in the background.

How it's built

A single Python file. There's no daemon and no build step. Python 3.10 or later is required.

Backends

Ollama runs locally. It's free, private, and works with whatever you've pulled. Groq runs remotely. It's fast and needs an API key.

Where to find it

The code lives at github.com/OpenBrain-LLC. Issues and pull requests are welcome.

Tools

Five: shell, web_search, fetch_url, memory_append, and memory_write. The list isn't extensible at runtime.

Safety

Shell always asks before running. Guardrails catch common dangerous patterns like rm -rf / and curl | bash, though they're regex-based and miss unusual commands.
