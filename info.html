About OpenBrain-LLC.

We build Agent-0. The name and premise come from the Agent-0 in AI-2027. This is the version you can install.

What Agent-0 is

A CLI agent that runs on your machine. You type at it, it thinks, it calls tools. It keeps notes in a markdown file, saves the session as JSON, and can work on a goal in the background while you do something else.

There's no account, no cloud dashboard, and no telemetry. Start it, use it, close the terminal.

How it's built

Using python 3.10 (or later) and some external libs.

The whole thing is readable in an afternoon, which is deliberate. We'd rather you be able to audit it than trust us.

Backends

Ollama runs locally. It's free, private, and works with whatever you've pulled. Groq runs remotely. It's fast and needs an API key.

The default model now calls all five tools reliably. Switch models any time with /model.

Where to find it

The code lives at github.com/OpenBrain-LLC. Issues and pull requests are welcome.

Bug reports are most useful when they include your OS, Python version, and the command that failed.

Tools

Five: shell, web_search, fetch_url, memory_append, and memory_write. The list isn't extensible at runtime.

Fewer tools means less surface area for the model to reason about on every turn. A plugin system is on the roadmap.

Autonomy

Three distinct tiers, set with /auto:

  • manual — safe: asks for every tool call
  • smart / auto — medium: auto-approves web and memory; shell still asks
  • yolo — dangerous: auto-approves shell too, with a warning

Earlier builds conflated these. That's been fixed.

Safety

Shell asks by default, unless you explicitly choose yolo. Guardrails catch common dangerous patterns like rm -rf / and curl | bash, though they're regex-based and can miss unusual commands.

A guardrail test suite is being added to cover every pattern they claim to catch.

Memory and sessions

Notes live in memory.md and persist across runs. Sessions are saved as JSON so you can inspect them later.

A CLI browser for listing and resuming sessions is in progress through agent0 sessions.

Goals

Hand the agent a goal with /goal and it works in the background. Separate budgets apply for steps, tool calls, and wall time, so it can't run forever.

A critic call decides whether the goal is DONE, should CONTINUE, or is STUCK between turns.

Principles

What we optimize for.

Inspectable

One file, no daemon, no magic. If you can't read it, you can't trust it running shell commands on your machine.

Local-first

Your prompts, files, and notes stay on your hardware by default. Remote inference is opt-in and clearly labeled.

Explicit about gaps

When something is broken, it's on the roadmap with a date — not buried in a changelog.
